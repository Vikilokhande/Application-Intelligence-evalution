# Green Infrastructure Support Scheme

This fictional scheme is for local development testing only.

Eligible organization types include Municipality, Registered NGO, Academic Institution, and Government Agency.

Required documents are Application Form, Project Proposal, Budget, and Certificate.

The configured maximum project cost is INR 5,000,000. The configured maximum project duration is 24 months.

Reviewer attention is required when financial values contradict across proposal and budget documents, when certificate identifiers are absent, or when document completeness is low.
